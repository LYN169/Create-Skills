# 地点名单转坐标 · 提示词模板（发给 Claude Code 直接使用）

**发给 Claude Code 只需要两行**（第一行固定照抄，第二行改成你的文件路径）：

```text
请把下面文件中的地点名单解析为坐标：
D:\路径\你的地点名单文件
```

其余全部按默认执行，无需在提示词里写要求。

---

## 使用须知（给人看的，不用粘贴）

**默认行为**（由技能规则固定，无需每次说明）：

- 输入文件支持 .doc / .docx / .xlsx / .csv / .txt，也可以直接粘贴文字名单；
- 按原顺序逐条解析，原内容列、行序、记录数量全部保留；
- 结果另存新文件（输入文件名后加“_坐标结果.xlsx”），**不覆盖输入文件**；
- 同时输出 .xlsx 和 .csv 各一份（CSV 为 UTF-8 BOM）；
- 结果表固定新增五个英文字段：
  `longitude_gcj02`、`latitude_gcj02`（高德原始坐标）、
  `longitude_wgs84`、`latitude_wgs84`（本地转换后的 WGS84）、
  `conversion_status`（转换状态）；
- 无法确认的地点四个坐标字段留空（不填 0,0、不用乡镇中心或村委会冒充），
  同名村落核实县乡归属、改名撤并查沿革依据。

**结果用法**（ArcGIS / QGIS 绘图）：

- X 选 `longitude_wgs84`，Y 选 `latitude_wgs84`，坐标系选 GCS_WGS_1984 / EPSG:4326；
- GCJ-02 两列只用于原始坐标追溯，不要标为 EPSG:4326，也不要与 WGS84 两列混用。

**特殊需求**（需要时才在提示词里加一句）：

- 输入坐标已是 WGS84（如 GPS 实测）：“输入坐标已经是 WGS84，不要再转换”；
- 只输出一种格式：“只输出 .xlsx”或“只输出 .csv”；
- 指定输出位置：“结果保存到 D:\某目录”。
